# 1. Физическая постановка

Модель является электростатическим PIC с внешними электромагнитными полями.

Самосогласованный потенциал плазмы вычисляется из уравнения Пуассона:

```python
laplacian(phi) = -rho / EPSILON_0
```

где полный объёмный заряд:

```python
rho = rho_electrons + rho_ions
```

После решения уравнения Пуассона вычисляется самосогласованное электрическое поле:

```python
E_self = -gradient(phi)
```

То есть:

```python
E_self_x = -dphi_dx
E_self_y = -dphi_dy
E_self_z = -dphi_dz
```

Полное электрическое поле, действующее на частицу:

```python
E_total = E_self

for module in external_modules:
    E_total += module.electric_field(
        positions=particle_positions,
        time=current_time,
    )
```

Полное магнитное поле:

```python
B_total = torch.zeros_like(particle_positions)

for module in external_modules:
    B_total += module.magnetic_field(
        positions=particle_positions,
        time=current_time,
    )
```

Собственное магнитное поле токов плазмы в этой версии не рассчитывается.

Также пока не рассчитываются:

* обратное влияние плазмы на амплитуду и фазу СВЧ-моды;
* изменение добротности резонатора;
* излучение частиц;
* столкновения частиц;
* ионизация;
* вторичная электронная эмиссия;
* отражение частиц от стенок.

Частицы, попавшие на физическую границу области, поглощаются.

## 2.2. Внешнее магнитное поле

Начальное магнитное поле должно соответствовать электронному циклотронному резонансу:

```python
B0 = ELECTRON_MASS * rf_omega / abs(ELEMENTARY_CHARGE)
```

Для `2.4 GHz` получится приблизительно:

```python
B0_tesla = 0.0857
```

Добавочное поле:

```python

```

Физическое время роста:

```python
magnetic_ramp_time_s = 100e-6
```

Закон изменения центрального магнитного поля:

```python
ramp_fraction = torch.clamp(
    time / magnetic_ramp_time_s,
    min=0.0,
    max=1.0,
)

B_mid = B0_tesla + delta_B_max_tesla * ramp_fraction
```

Использовать магнитное зеркальное отношение:

```python
mirror_ratio = 1.02
```

Также разрешить конфигурационное значение:

```python
mirror_ratio = 1.05
```

`1.02` использовать в стандартном численном профиле.

`1.05` оставить как вариант, близкий к экспериментальной конфигурации.

## 2.3. Начальная плазма

Плазма водородная:

```python
species = ["electrons", "protons"]
```

Начальная концентрация:

```python
electron_density_m3 = 4.0e16
proton_density_m3 = 4.0e16
```

Начальная температура электронов:

```python
electron_temperature_ev = 20.0
```

Начальная температура протонов:

```python
proton_temperature_ev = 1.0
```

Начальное облако представляет собой электрически нейтральный цилиндр:

```python
plasma_radius_m = 0.004
plasma_length_m = 0.04
```

Цилиндр расположен по центру резонатора и соосен с осью `z`.

Распределение частиц должно быть равномерным по объёму.

Корректная генерация положения внутри цилиндра:

```python
u_radius = torch.rand(num_particles, device=device)
u_angle = torch.rand(num_particles, device=device)
u_z = torch.rand(num_particles, device=device)

radius = plasma_radius_m * torch.sqrt(u_radius)
theta = 2.0 * math.pi * u_angle

x = radius * torch.cos(theta)
y = radius * torch.sin(theta)

z = (
    plasma_center_z
    + plasma_length_m * (u_z - 0.5)
)
```

Не использовать:

```python
radius = plasma_radius_m * u_radius
```

так как это создаёт неправильное распределение плотности по радиусу.

Начальные скорости задавать из изотропного распределения Максвелла.

Для каждой декартовой компоненты скорости можно использовать:

```python
temperature_joule = temperature_ev * ELEMENTARY_CHARGE

velocity_std = math.sqrt(
    temperature_joule / particle_mass
)

velocities = torch.randn(
    num_particles,
    3,
    device=device,
    dtype=dtype,
) * velocity_std
```

После генерации убрать остаточную среднюю скорость:

```python
velocities -= velocities.mean(dim=0, keepdim=True)
```

Использовать quiet start:

* электрон и соответствующий ему протон начинают в одной позиции;
* тепловые скорости электронов и протонов генерируются отдельно;
* средний импульс каждого вида должен быть близок к нулю;
* начальное распределение суммарного заряда должно быть максимально близко к нейтральному.

# 4. Пространственная сетка

Используется только трёхмерная декартова сетка.

Никакой цилиндрической или полярной вычислительной сетки быть не должно.

Основные тензоры:

```python
rho.shape == (nx, ny, nz)
phi.shape == (nx, ny, nz)

electric_field.shape == (nx, ny, nz, 3)
```

Допускается хранение компонентов отдельными тензорами:

```python
ex.shape == (nx, ny, nz)
ey.shape == (nx, ny, nz)
ez.shape == (nx, ny, nz)
```

Область сетки для цилиндрического резонатора:

```python
x_min = -resonator_radius_m
x_max = +resonator_radius_m

y_min = -resonator_radius_m
y_max = +resonator_radius_m

z_min = -resonator_length_m / 2.0
z_max = +resonator_length_m / 2.0
```

Координаты узлов:

```python
x = torch.linspace(x_min, x_max, nx, device=device)
y = torch.linspace(y_min, y_max, ny, device=device)
z = torch.linspace(z_min, z_max, nz, device=device)
```

Шаги:

```python
dx = (x_max - x_min) / (nx - 1)
dy = (y_max - y_min) / (ny - 1)
dz = (z_max - z_min) / (nz - 1)
```

Цилиндрическая форма задаётся булевой маской внутри декартова массива:

```python
x_grid = x[:, None, None]
y_grid = y[None, :, None]
z_grid = z[None, None, :]

radial_inside = (
    x_grid**2 + y_grid**2
    < resonator_radius_m**2
)

axial_inside = (
    torch.abs(z_grid)
    < resonator_length_m / 2.0
)

interior_mask = radial_inside & axial_inside
```

Сетка остаётся прямоугольным трёхмерным тензором.

# 5. Разделение Domain и внешних модулей

Архитектурно не связывай PIC-ядро напрямую с цилиндрическим резонатором.

Симуляция всегда должна иметь объект `Domain`.

`Domain` определяет:

* размеры вычислительной сетки;
* координатные границы;
* внутренние узлы;
* граничные узлы;
* область, доступную частицам;
* граничные условия потенциала;
* правило поглощения частиц.

Реализуй минимум два domain.

## 5.1. BoxDomain

Обычный прямоугольный параллелепипед.

Используется, когда эксперимент запускается только с самосогласованным полем и без резонатора.

Граничное условие по умолчанию:

```python
phi = 0.0
```

на шести внешних гранях коробки.

Пример API:

```python
domain = BoxDomain(
    x_bounds=(-0.05, 0.05),
    y_bounds=(-0.05, 0.05),
    z_bounds=(-0.05, 0.05),
    grid_shape=(128, 128, 128),
    boundary_potential=0.0,
)
```

## 5.2. CylindricalPECDomain

Цилиндр внутри декартовой сетки.

Используется при моделировании цилиндрического резонатора.

На боковой стенке и торцах:

```python

```

В первой версии допустима stair-step аппроксимация цилиндрической границы по воксельной маске.

Embedded boundary и cut-cell оставить как будущие расширения.

# 7. Модуль TE111CylindricalResonator

Модуль должен предоставлять:

* аналитическое СВЧ-электрическое поле;
* аналитическое СВЧ-магнитное поле;
* визуализатор цилиндра;
* метаданные режима.

Использовать вращающуюся `TE111`-моду.

Вращающуюся моду сформировать из двух вырожденных ортогональных `TE111`-мод со сдвигом фазы на четверть периода.

Концептуально:

```python
mode_a_phase = rf_omega * time
mode_b_phase = rf_omega * time + math.pi / 2.0

E_rf = E_mode_a * torch.cos(mode_a_phase)
E_rf += E_mode_b * torch.cos(mode_b_phase)
```

Либо эквивалентная синус-косинусная запись.

Все формулы поля вынести в отдельный файл.

Добавить подробные комментарии:

* система координат;
* направление оси;
* фазовое соглашение;
* нормировка;
* используемый корень функции Бесселя;
* единицы измерения;
* связь заданного `E0` с амплитудой аналитической моды.

Использовать:

```python
TE11_ROOT = 1.841183781
```

Поперечное волновое число:

```python
k_r = TE11_ROOT / resonator_radius_m
```

Продольное волновое число для первой продольной гармоники:

```python
k_z = math.pi / resonator_length_m
```

Полное волновое число:

```python
k = math.sqrt(k_r**2 + k_z**2)
```

Соответствующая собственная частота идеальной полости:

```python
mode_omega = SPEED_OF_LIGHT * k
mode_frequency = mode_omega / (2.0 * math.pi)
```

Добавить проверку, насколько `mode_frequency` отличается от заданной `rf_frequency_hz`.

Не вычислять Bessel-функции через SciPy внутри каждого временного шага на CPU.

Использовать:

* доступные операции PyTorch;
* либо заранее построенную lookup table;
* либо предвычисленный пространственный профиль на сетке;
* либо собственную небольшую реализацию необходимых функций.

Предусмотреть две стратегии:

```python
field_evaluation_mode = "particle_positions"
```

и:

```python
field_evaluation_mode = "precomputed_grid"
```

В режиме `particle_positions` поле вычисляется напрямую в позициях частиц.

В режиме `precomputed_grid` пространственные коэффициенты вычисляются один раз на сетке, после чего интерполируются к частицам.

По умолчанию выбрать стратегию, которая окажется быстрее по результатам профилирования.

Поле должно быть нулевым вне физической полости:

```python
inside = (
    positions[:, 0] ** 2
    + positions[:, 1] ** 2
    < resonator_radius_m**2
) & (
    torch.abs(positions[:, 2])
    < resonator_length_m / 2.0
)

E_rf = torch.where(
    inside[:, None],
    E_rf,
    torch.zeros_like(E_rf),
)
```

Добавить плавную временную огибающую включения СВЧ.

Количество периодов включения:

```python
rf_ramp_cycles = 10
```

Длительность включения:

```python
rf_period = 1.0 / rf_frequency_hz
rf_ramp_time = rf_ramp_cycles * rf_period
```

Огибающая:

```python
if time <= 0.0:
    envelope = 0.0
elif time < rf_ramp_time:
    phase = math.pi * time / (2.0 * rf_ramp_time)
    envelope = math.sin(phase) ** 2
else:
    envelope = 1.0
```

Итоговое поле:

```python
E_rf *= envelope
B_rf *= envelope
```

Не включать поле мгновенным скачком.

# 8. Модуль RampedMirrorMagneticField

Модуль должен возвращать:

* внешнее магнитное поле;
* соответствующее приближённое индукционное электрическое поле;
* визуализатор магнитных катушек.

Центральное поле:

```python
ramp_fraction = torch.clamp(
    time / ramp_time_s,
    min=0.0,
    max=1.0,
)

B_mid = B0 + delta_B_max * ramp_fraction
```

Производная поля во время линейного участка:

```python
if 0.0 < time < ramp_time_s:
    dB_mid_dt = delta_B_max / ramp_time_s
else:
    dB_mid_dt = 0.0
```

Осевой профиль зеркального поля:

```python
normalized_z = 2.0 * z / resonator_length_m

mirror_profile = (
    1.0
    + (mirror_ratio - 1.0)
    * normalized_z**2
)

B_z = B_mid * mirror_profile
```

При таком профиле:

```python
B_z(z=0) == B_mid
B_z(z=+-L/2) == B_mid * mirror_ratio
```

Производная осевого профиля:

```python
d_mirror_profile_dz = (
    8.0
    * (mirror_ratio - 1.0)
    * z
    / resonator_length_m**2
)

dBz_dz = B_mid * d_mirror_profile_dz
```

В параксиальном приближении радиальная компонента:

```python
r = torch.sqrt(x**2 + y**2)

B_r = -0.5 * r * dBz_dz
```

Переход к декартовым компонентам:

```python
safe_r = torch.clamp(r, min=1e-20)

B_x = B_r * x / safe_r
B_y = B_r * y / safe_r
```

На оси установить:

```python
axis_mask = r < 1e-12

B_x = torch.where(axis_mask, 0.0, B_x)
B_y = torch.where(axis_mask, 0.0, B_y)
```

Итоговое магнитное поле:

```python
B = torch.stack(
    [B_x, B_y, B_z],
    dim=-1,
)
```

Изменяющееся осевое магнитное поле создаёт индукционное азимутальное электрическое поле.

В декартовых координатах использовать:

```python
E_induced_x = +0.5 * y * dB_mid_dt
E_induced_y = -0.5 * x * dB_mid_dt
E_induced_z = torch.zeros_like(E_induced_x)
```

Итог:

```python
E_induced = torch.stack(
    [
        E_induced_x,
        E_induced_y,
        E_induced_z,
    ],
    dim=-1,
)
```

Явно задокументировать, что это приближение для преимущественно осевого и медленно изменяющегося поля.

Модуль должен предоставлять scene renderer магнитной системы:

* две группы катушек или магнитных колец около торцов;
* визуальная геометрия не влияет на физическое поле;
* размеры визуальных объектов конфигурируемы;
* при отключённом модуле никаких магнитов в Rerun быть не должно.

# 10. Cloud-In-Cell

Использовать трёхмерный Cloud-In-Cell.

Каждая частица распределяет заряд между восемью соседними узлами.

Реализация должна быть векторизованной.

Для позиции частицы:

```python
normalized_x = (particle_x - x_min) / dx
normalized_y = (particle_y - y_min) / dy
normalized_z = (particle_z - z_min) / dz
```

Нижние индексы:

```python
i0 = torch.floor(normalized_x).to(torch.int64)
j0 = torch.floor(normalized_y).to(torch.int64)
k0 = torch.floor(normalized_z).to(torch.int64)
```

Дробная часть:

```python
fx = normalized_x - i0
fy = normalized_y - j0
fz = normalized_z - k0
```

Верхние индексы:

```python
i1 = i0 + 1
j1 = j0 + 1
k1 = k0 + 1
```

Восемь весов:

```python
w000 = (1-fx) * (1-fy) * (1-fz)
w100 = fx     * (1-fy) * (1-fz)
w010 = (1-fx) * fy     * (1-fz)
w110 = fx     * fy     * (1-fz)

w001 = (1-fx) * (1-fy) * fz
w101 = fx     * (1-fy) * fz
w011 = (1-fx) * fy     * fz
w111 = fx     * fy     * fz
```

Преобразование индекса в плоский индекс:

```python
flat_index = (
    i * ny * nz
    + j * nz
    + k
)
```

Накопление заряда:

```python
flat_charge_grid.scatter_add_(
    dim=0,
    index=flat_indices,
    src=particle_charge * weights,
)
```

Плотность заряда:

```python
cell_volume = dx * dy * dz
rho = charge_grid / cell_volume
```

Обязательно проверить сохранение заряда:

```python
grid_total_charge = rho.sum() * cell_volume
particle_total_charge = particle_charges.sum()

relative_charge_error = (
    abs(grid_total_charge - particle_total_charge)
    / max(abs(particle_total_charge), 1e-30)
)
```

Для электрически нейтральной плазмы знаменатель по суммарному заряду может быть близок к нулю.

Поэтому дополнительно использовать абсолютную ошибку и нормировку на сумму модулей зарядов:

```python
charge_scale = particle_charges.abs().sum()

normalized_charge_error = (
    abs(grid_total_charge - particle_total_charge)
    / max(charge_scale, 1e-30)
)
```

Для интерполяции поля обратно к частицам использовать те же индексы и веса:

```python
particle_field = (
    w000[:, None] * field[i0, j0, k0]
    + w100[:, None] * field[i1, j0, k0]
    + w010[:, None] * field[i0, j1, k0]
    + w110[:, None] * field[i1, j1, k0]
    + w001[:, None] * field[i0, j0, k1]
    + w101[:, None] * field[i1, j0, k1]
    + w011[:, None] * field[i0, j1, k1]
    + w111[:, None] * field[i1, j1, k1]
)
```

Не использовать один метод для deposition и другой для gathering.

Создать функции:

```python
deposit_charge_cic(...)
gather_field_cic(...)
```

Добавить медленную CPU-reference реализацию для маленьких тестов.

Для MPS сначала использовать стандартные операции PyTorch.

Если `scatter_add_` окажется узким местом, предусмотреть backend-specific реализацию, но только после появления корректной базовой версии.

# 11. Решение уравнения Пуассона

Не использовать FFT как основной решатель.

Причина: цилиндрическая PEC-граница задаётся маской внутри декартова массива и не совпадает с внешними гранями прямоугольной FFT/DST-области.

Решается уравнение:

```python
-negative_laplacian(phi) = rho / EPSILON_0
```

Определить:

```python
A(phi) = -discrete_laplacian(phi)
b = rho / EPSILON_0
```

После чего решать:

```python
A(phi) = b
```

Использовать matrix-free Preconditioned Conjugate Gradient на PyTorch.

## 11.1. Дискретный оператор

Для внутреннего узла:

```python
A_phi[i, j, k] = (
    (
        2.0 * phi[i, j, k]
        - phi[i - 1, j, k]
        - phi[i + 1, j, k]
    ) / dx**2
    +
    (
        2.0 * phi[i, j, k]
        - phi[i, j - 1, k]
        - phi[i, j + 1, k]
    ) / dy**2
    +
    (
        2.0 * phi[i, j, k]
        - phi[i, j, k - 1]
        - phi[i, j, k + 1]
    ) / dz**2
)
```

Значения соседей вне `interior_mask` считать равными нулю:

```python
phi_outside_domain = 0.0
```

Это реализует заземлённое Dirichlet boundary condition.

## 11.2. Matrix-free оператор

Не создавать полную sparse-матрицу.

Реализовать:

```python
def apply_negative_laplacian(
    phi: torch.Tensor,
    interior_mask: torch.Tensor,
    spacing: tuple[float, float, float],
) -> torch.Tensor:
    ...
```

Оператор должен:

* принимать тензор `(nx, ny, nz)`;
* использовать tensor slicing;
* считать значения вне `interior_mask` равными нулю;
* возвращать ноль вне области неизвестных;
* корректно реализовывать Dirichlet boundary;
* не использовать `torch.roll`, если он создаёт периодическую связь между противоположными сторонами.

Допустимая схема:

```python
masked_phi = torch.where(
    interior_mask,
    phi,
    torch.zeros_like(phi),
)

result = torch.zeros_like(phi)

center = masked_phi[1:-1, 1:-1, 1:-1]

x_minus = masked_phi[:-2, 1:-1, 1:-1]
x_plus = masked_phi[2:, 1:-1, 1:-1]

y_minus = masked_phi[1:-1, :-2, 1:-1]
y_plus = masked_phi[1:-1, 2:, 1:-1]

z_minus = masked_phi[1:-1, 1:-1, :-2]
z_plus = masked_phi[1:-1, 1:-1, 2:]

result[1:-1, 1:-1, 1:-1] = (
    (2.0 * center - x_minus - x_plus) / dx**2
    + (2.0 * center - y_minus - y_plus) / dy**2
    + (2.0 * center - z_minus - z_plus) / dz**2
)

result *= interior_mask
```

Проверить корректность этой реализации около маски цилиндра.

## 11.3. PCG

Реализовать собственный PCG, работающий с 3D-тензорами.

Концептуальный алгоритм:

```python
x = initial_guess

r = b - A(x)
z = preconditioner.apply(r)
p = z.clone()

rz_old = masked_dot(r, z)

for iteration in range(max_iterations):
    Ap = A(p)

    denominator = masked_dot(p, Ap)

    alpha = rz_old / denominator

    x = x + alpha * p
    r = r - alpha * Ap

    check_convergence(r)

    z = preconditioner.apply(r)

    rz_new = masked_dot(r, z)

    beta = rz_new / rz_old

    p = z + beta * p

    rz_old = rz_new
```

Скалярное произведение считать только внутри маски:

```python
def masked_dot(
    a: torch.Tensor,
    b: torch.Tensor,
    mask: torch.Tensor,
) -> torch.Tensor:
    return torch.sum(
        a[mask] * b[mask]
    )
```

Для производительности допускается:

```python
return torch.sum(
    a * b * mask
)
```

где `mask` приведена к dtype тензора.

Начальное приближение:

```python
phi_initial = previous_phi
```

Если это первый шаг:

```python
phi_initial = torch.zeros_like(rho)
```

Если правая часть практически нулевая:

```python
if torch.linalg.vector_norm(b[interior_mask]) < tiny_value:
    return torch.zeros_like(b)
```

Конфигурация:

```python
relative_tolerance = 1e-5
absolute_tolerance = 0.0
max_iterations = 200
```

Норма правой части:

```python
b_norm = torch.linalg.vector_norm(
    b[interior_mask]
)
```

Норма невязки:

```python
residual_norm = torch.linalg.vector_norm(
    residual[interior_mask]
)
```

Критерий сходимости:

```python
threshold = max(
    absolute_tolerance,
    relative_tolerance * max(b_norm, tiny_value),
)

converged = residual_norm <= threshold
```

Также вычислять:

```python
relative_residual = (
    residual_norm
    / max(b_norm, tiny_value)
)
```

Проверять:

```python
torch.isfinite(phi).all()
torch.isfinite(residual).all()
```

## 11.4. Предобуславливатель

Первая версия:



но не делать multigrid обязательным для первого рабочего результата.

# 12. Интегрирование движения частиц

Использовать релятивистский Boris pusher.

Не использовать RK4 как основной метод.

Состояние частицы:

```python
position.shape == (num_particles, 3)
momentum.shape == (num_particles, 3)
```

Релятивистский gamma по импульсу:

```python
momentum_squared = torch.sum(
    momentum * momentum,
    dim=-1,
    keepdim=True,
)

gamma = torch.sqrt(
    1.0
    + momentum_squared
    / (mass**2 * SPEED_OF_LIGHT**2)
)
```

Скорость:

```python
velocity = momentum / (gamma * mass)
```

Концептуальная схема Boris:

```python
half_electric_impulse = (
    charge
    * electric_field
    * dt
    / 2.0
)

p_minus = momentum + half_electric_impulse
```

Gamma после первого half-kick:

```python
gamma_minus = torch.sqrt(
    1.0
    + torch.sum(
        p_minus * p_minus,
        dim=-1,
        keepdim=True,
    )
    / (mass**2 * SPEED_OF_LIGHT**2)
)
```

Вектор вращения:

```python
t = (
    charge
    * magnetic_field
    * dt
    / (2.0 * gamma_minus * mass)
)
```

Вспомогательный вектор:

```python
t_squared = torch.sum(
    t * t,
    dim=-1,
    keepdim=True,
)

s = 2.0 * t / (1.0 + t_squared)
```

Магнитное вращение:

```python
p_prime = p_minus + torch.cross(
    p_minus,
    t,
    dim=-1,
)

p_plus = p_minus + torch.cross(
    p_prime,
    s,
    dim=-1,
)
```

Второй электрический half-kick:

```python
new_momentum = (
    p_plus
    + half_electric_impulse
)
```

Новая скорость:

```python
new_gamma = torch.sqrt(
    1.0
    + torch.sum(
        new_momentum * new_momentum,
        dim=-1,
        keepdim=True,
    )
    / (mass**2 * SPEED_OF_LIGHT**2)
)

new_velocity = (
    new_momentum
    / (new_gamma * mass)
)
```

Новое положение:

```python
new_position = position + new_velocity * dt
```

Использовать один общий pusher для электронов и протонов.

Для протонов формула остаётся релятивистской, даже если фактически:

```python
proton_gamma ~= 1.0
```

Структура состояний должна быть согласована с leapfrog.

Нужно явно задокументировать, в какие моменты времени хранятся:

* координаты;
* импульсы;
* электрическое поле;
* магнитное поле.

Поля для push желательно вычислять в момент:

```python
field_time = current_time + 0.5 * dt
```

Добавить unit tests:

### Частица без полей

```python
E = 0
B = 0
```

Ожидается:

```python
momentum_new == momentum_old
position_new == position_old + velocity * dt
```

### Постоянное электрическое поле

```python
B = 0
E = constant
```

Ожидается:

```python
momentum(t) ~= momentum(0) + charge * E * t
```

### Постоянное магнитное поле

```python
E = 0
B = constant
```

Ожидается:

* модуль импульса сохраняется;
* кинетическая энергия сохраняется;
* траектория вращается вокруг направления `B`.

### Ограничение скорости

После каждого теста:

```python
speed = torch.linalg.vector_norm(
    velocity,
    dim=-1,
)

assert torch.all(
    speed < SPEED_OF_LIGHT * (1.0 + tolerance)
)
```

# 25. Диагностика физических масштабов

При создании эксперимента вычислять и выводить следующие величины.

## RF period

```python
rf_period_s = 1.0 / rf_frequency_hz
```

## Electron cyclotron angular frequency

```python
electron_cyclotron_omega = (
    abs(ELEMENTARY_CHARGE)
    * magnetic_field_tesla
    / ELECTRON_MASS
)
```

Релятивистская частота для конкретной частицы:

```python
relativistic_cyclotron_omega = (
    abs(ELEMENTARY_CHARGE)
    * magnetic_field_tesla
    / (gamma * ELECTRON_MASS)
)
```

## Proton cyclotron angular frequency

```python
proton_cyclotron_omega = (
    ELEMENTARY_CHARGE
    * magnetic_field_tesla
    / PROTON_MASS
)
```

## Electron plasma angular frequency

```python
electron_plasma_omega = math.sqrt(
    electron_density_m3
    * ELEMENTARY_CHARGE**2
    / (
        ELECTRON_MASS
        * EPSILON_0
    )
)
```

## Debye length

```python
electron_temperature_joule = (
    electron_temperature_ev
    * ELEMENTARY_CHARGE
)

debye_length_m = math.sqrt(
    EPSILON_0
    * electron_temperature_joule
    / (
        electron_density_m3
        * ELEMENTARY_CHARGE**2
    )
)
```

## Grid-to-Debye ratios

```python
dx_over_debye = dx / debye_length_m
dy_over_debye = dy / debye_length_m
dz_over_debye = dz / debye_length_m
```

## Plasma frequency timestep criterion

```python
omega_pe_dt = electron_plasma_omega * dt_s
```

## Steps per RF period

```python
steps_per_rf_period = rf_period_s / dt_s
```

## Real particle count

```python
real_particle_count = density_m3 * plasma_volume
```

## Macro weight

```python
macro_weight = (
    real_particle_count
    / num_macro_particles
)
```

## Approximate macroparticles per occupied cell

Сначала оценить объём одной ячейки:

```python
cell_volume = dx * dy * dz
```

Количество ячеек в начальном плазменном объёме:

```python
occupied_cell_count_estimate = (
    plasma_volume / cell_volume
)
```

Макрочастиц на занятую ячейку:

```python
macro_particles_per_cell = (
    num_macro_particles
    / occupied_cell_count_estimate
)
```

Если:

```python
max(dx, dy, dz) > debye_length_m
```

вывести заметное предупреждение.

Если:

```python
macro_particles_per_cell < 5
```

также вывести предупреждение о сильном PIC-шуме.

Не останавливать запуск автоматически.

## 29.5. Manufactured solution для BoxDomain

Использовать координаты от `0` до соответствующего размера коробки.

```python
phi_exact = (
    torch.sin(math.pi * x / Lx)
    * torch.sin(math.pi * y / Ly)
    * torch.sin(math.pi * z / Lz)
)
```

Для этой функции:

```python
lambda_value = (
    (math.pi / Lx) ** 2
    + (math.pi / Ly) ** 2
    + (math.pi / Lz) ** 2
)
```

Так как:

```python
-negative_laplacian(phi_exact) = (
    lambda_value * phi_exact
)
```

задать:

```python
b = lambda_value * phi_exact
```

или:

```python
rho = EPSILON_0 * b
```

Проверить:

* PCG сходится;
* относительная ошибка потенциала мала;
* ошибка уменьшается при измельчении сетки.

Ошибка:

```python
relative_error = (

)
```

## 29.8. Neutral plasma

После quiet start:

Значение должно быть малым.

# 33. Важные ограничения и честность результатов

В README и metadata явно указать:

```text
The cylindrical PEC wall currently uses a stair-step voxel mask.

The simulation computes electrostatic self-consistent electric fields only.

The plasma self-generated magnetic field is not computed.

The plasma does not modify the prescribed RF cavity mode.

Particle collisions are not included.

Ionization is not included.

Secondary electron emission is not included.

The development grid may not resolve the Debye length.

The scaled magnetic ramp is nonphysical and exists for demonstration only.

A direct 100 microsecond simulation resolving 2.4 GHz RF oscillations
requires an extremely large number of timesteps.
```

Не скрывать numerical warnings ради красивой визуализации.

Главный приоритет:

```text
1. Correctness
2. Tests
3. Modular architecture
4. Reproducibility
5. Visualization
6. Performance optimization
```

Сначала создать корректный, проверяемый и модульный PIC-код.

Только после этого заниматься:

* custom GPU kernels;
* Metal shaders;
* multigrid;
* production-size experiments;
* более сложной физикой.
