# Дополнение: отдельное окно Rerun и несколько Jupyter Notebook

Измени организацию исследовательской части проекта.

Не использовать один общий notebook для всех сценариев. Создать несколько отдельных Jupyter Notebook, каждый из которых демонстрирует один конкретный уровень физической модели.

Rerun Viewer должен запускаться в отдельном нативном окне, а не встраиваться внутрь notebook.

Использовать концептуально такой режим:

```python
import rerun as rr

rr.init(
    application_id="gyrac_pic",
    spawn=True,
)
```

Либо актуальный эквивалент API установленной версии Rerun:

```python
rr.init("gyrac_pic")
rr.spawn()
```

После запуска notebook должен открываться отдельный процесс Rerun Viewer.

Все последующие вызовы:

```python
rr.log(...)
```

должны стримить данные в это отдельное окно.

Не использовать `rr.notebook_show()` как основной способ визуализации.

Архитектура визуализации по-прежнему должна быть скрыта за:

```python
RerunVisualizationSink
```

Notebook не должен содержать прямые вызовы `rr.log(...)`, кроме, возможно, минимального демонстрационного или отладочного примера.

Основной код должен выглядеть примерно так:

```python
visualization_config = VisualizationConfig(
    mode="external",
    spawn_viewer=True,
    recording_path=None,
)

experiment = Experiment.create(
    config=config,
    domain=domain,
    modules=modules,
    visualization_config=visualization_config,
)
```

Для одновременного отдельного окна и записи в файл:

```python
visualization_config = VisualizationConfig(
    mode="external_and_file",
    spawn_viewer=True,
    recording_path=Path("runs/example/run.rrd"),
)
```

## Структура notebook

Создать минимум три отдельных notebook:

```text
notebooks/
├── 01_self_field_only.ipynb
├── 02_plasma_with_resonator.ipynb
└── 03_full_gyrac_experiment.ipynb
```

Каждый notebook должен быть коротким и использовать одну и ту же библиотеку проекта.

Не копировать между notebook реализацию:

* PIC;
* CIC;
* PCG;
* Boris pusher;
* Rerun renderers;
* инициализацию частиц;
* расчёт диагностик.

Notebook должны различаться главным образом конфигурацией `Domain` и списком подключённых модулей.

# Notebook 1: только самосогласованное поле

Файл:

```text
notebooks/01_self_field_only.ipynb
```

Назначение:

* создать начальный цилиндр нейтральной водородной плазмы;
* использовать электроны и протоны;
* не подключать резонатор;
* не подключать внешнее магнитное поле;
* рассчитывать только самосогласованное электрическое поле плазмы;
* сначала показать начальное состояние в отдельном окне Rerun;
* затем отдельной ячейкой запустить симуляцию.

Использовать `BoxDomain`.

Пример конфигурации:

```python
domain = BoxDomain(
    x_bounds=(-0.05, 0.05),
    y_bounds=(-0.05, 0.05),
    z_bounds=(-0.05, 0.05),
    grid_shape=config.grid.shape,
    boundary_potential=0.0,
)

modules = []
```

В этом notebook внешние поля должны быть равны нулю:

```python
E_external = 0
B_external = 0
```

Полное поле:

```python
E_total = E_self
B_total = 0
```

## Требуемые ячейки notebook 1

### Ячейка 1: imports

```python
from pathlib import Path

import torch

from gyrac_pic import (
    Experiment,
    BoxDomain,
    make_smoke_config,
    make_development_config,
)
```

### Ячейка 2: конфигурация

```python
config = make_smoke_config()

config.name = "self_field_only"
config.visualization.mode = "external"
config.visualization.spawn_viewer = True
```

### Ячейка 3: создание domain и experiment

```python
domain = BoxDomain(...)
modules = []

experiment = Experiment.create(
    config=config,
    domain=domain,
    modules=modules,
)
```

### Ячейка 4: вывод параметров

```python
experiment.print_configuration()
experiment.print_physical_scales()
```

Показать:

* размер domain;
* размер сетки;
* шаги сетки;
* число электронов;
* число протонов;
* плотность;
* температуры;
* macro weights;
* Debye length;
* plasma frequency;
* timestep;
* число частиц на занятую ячейку.

### Ячейка 5: инициализация начального состояния

```python
experiment.initialize()
```

После этой команды частицы и сетка должны быть созданы, но simulation time ещё должен оставаться равным нулю:

```python
experiment.state.step == 0
experiment.state.time_s == 0.0
```

### Ячейка 6: показать начальное состояние

```python
experiment.visualize_initial_state()
```

Эта команда должна:

* запустить отдельное окно Rerun, если оно ещё не запущено;
* очистить или создать новую recording session;
* показать начальный цилиндр электронов и протонов;
* показать границы `BoxDomain`;
* показать декартову сетку в разреженном виде;
* показать начальные графики с первой точкой при `time = 0`;
* не выполнять ни одного simulation step.

После выполнения этой ячейки пользователь должен иметь возможность осмотреть начальный цилиндр плазмы в отдельном окне Rerun до начала вычислений.

### Ячейка 7: запуск симуляции

```python
experiment.run(
    num_steps=config.num_steps,
)
```

Во время выполнения данные должны стримиться в уже открытое окно Rerun.

В сцене не должно быть:

* цилиндрического резонатора;
* магнитов;
* катушек;
* стрелок внешнего магнитного поля.

# Notebook 2: плазма и резонатор без магнитов

Файл:

```text
notebooks/02_plasma_with_resonator.ipynb
```

Назначение:

* создать цилиндр плазмы;
* поместить его внутрь цилиндрического резонатора;
* подключить СВЧ-моду `TE111CylindricalResonator`;
* не подключать внешний магнитный модуль;
* показать начальное состояние в отдельном окне Rerun;
* затем отдельной ячейкой запустить симуляцию.

Использовать:

```python
domain = CylindricalPECDomain(...)
```

Подключить:

```python
modules = [
    TE111CylindricalResonator(...),
]
```

Не подключать:

```python
RampedMirrorMagneticField
```

Полные поля:

```python
E_total = E_self + E_rf
B_total = B_rf
```

## Требуемые ячейки notebook 2

Использовать тот же порядок ячеек:

1. Imports.
2. Configuration.
3. Domain and modules.
4. Experiment creation.
5. Configuration and physical-scale output.
6. Initialization.
7. Initial visualization.
8. Simulation run.
9. Optional checkpoint save.
10. Optional `.rrd` save or recording path output.

Пример создания:

```python
config = make_smoke_config()

config.name = "plasma_with_resonator"
config.visualization.mode = "external"
config.visualization.spawn_viewer = True

domain = CylindricalPECDomain(
    radius_m=config.resonator.radius_m,
    length_m=config.resonator.length_m,
    grid_shape=config.grid.shape,
    boundary_potential=0.0,
)

resonator = TE111CylindricalResonator(
    radius_m=config.resonator.radius_m,
    length_m=config.resonator.length_m,
    frequency_hz=config.resonator.frequency_hz,
    electric_field_amplitude_v_per_m=(
        config.resonator.electric_field_amplitude_v_per_m
    ),
    rf_ramp_cycles=config.resonator.rf_ramp_cycles,
)

modules = [
    resonator,
]

experiment = Experiment.create(
    config=config,
    domain=domain,
    modules=modules,
)
```

Начальная визуализация:

```python
experiment.initialize()
experiment.visualize_initial_state()
```

В Rerun должны появиться:

* электроны;
* протоны;
* начальный цилиндр плазмы;
* полупрозрачная боковая поверхность резонатора;
* торцы резонатора;
* ось резонатора;
* разреженная декартова сетка.

В Rerun не должно быть:

* магнитных катушек;
* внешнего магнитного поля;
* magnetic module entities.

После запуска:

```python
experiment.run(
    num_steps=config.num_steps,
)
```

частицы должны двигаться под действием:

```python
E_self
E_rf
B_rf
```

# Notebook 3: полный GYRAC

Файл:

```text
notebooks/03_full_gyrac_experiment.ipynb
```

Назначение:

* создать цилиндр плазмы;
* использовать цилиндрический резонатор;
* подключить вращающуюся `TE111`-моду;
* подключить растущее зеркальное магнитное поле;
* двигать электроны и протоны;
* показать начальное состояние в отдельном Rerun Viewer;
* затем отдельной ячейкой запустить полную симуляцию.

Использовать:

```python
domain = CylindricalPECDomain(...)
```

Подключить:

```python
modules = [
    TE111CylindricalResonator(...),
    RampedMirrorMagneticField(...),
]
```

Полные поля:

```python
E_total = (
    E_self
    + E_rf
    + E_induced
)

B_total = (
    B_rf
    + B_external
)
```

Пример:

```python
config = make_classic_gyrac_x_smoke_config()

config.name = "full_gyrac"
config.visualization.mode = "external_and_file"
config.visualization.spawn_viewer = True
config.visualization.recording_path = Path(
    "runs/full_gyrac/run.rrd"
)

domain = CylindricalPECDomain(
    radius_m=config.resonator.radius_m,
    length_m=config.resonator.length_m,
    grid_shape=config.grid.shape,
    boundary_potential=0.0,
)

resonator = TE111CylindricalResonator(
    radius_m=config.resonator.radius_m,
    length_m=config.resonator.length_m,
    frequency_hz=config.resonator.frequency_hz,
    electric_field_amplitude_v_per_m=(
        config.resonator.electric_field_amplitude_v_per_m
    ),
    rf_ramp_cycles=config.resonator.rf_ramp_cycles,
)

magnetic_field = RampedMirrorMagneticField(
    B0_tesla=config.magnetic_field.B0_tesla,
    delta_B_max_tesla=(
        config.magnetic_field.delta_B_max_tesla
    ),
    ramp_time_s=config.magnetic_field.ramp_time_s,
    mirror_ratio=config.magnetic_field.mirror_ratio,
    resonator_length_m=config.resonator.length_m,
)

modules = [
    resonator,
    magnetic_field,
]

experiment = Experiment.create(
    config=config,
    domain=domain,
    modules=modules,
)
```

Затем:

```python
experiment.print_configuration()
experiment.print_physical_scales()

experiment.initialize()
experiment.visualize_initial_state()
```

После этой ячейки пользователь должен увидеть в отдельном окне Rerun:

* начальный цилиндр электронов;
* начальный цилиндр протонов;
* полупрозрачный резонатор;
* две магнитные катушки или группы магнитов;
* направление внешнего магнитного поля;
* ось установки;
* декартову сетку;
* начальные значения графиков.

Следующей отдельной ячейкой:

```python
experiment.run(
    num_steps=config.num_steps,
)
```

Во время работы должны обновляться:

* положения частиц;
* цвета частиц по энергии;
* средняя энергия электронов;
* максимальная энергия электронов;
* средняя энергия протонов;
* число живых частиц;
* потери на стенки;
* параметры PCG;
* текущее значение внешнего магнитного поля;
* simulation step;
* physical simulation time.

# Общий lifecycle эксперимента

Для всех notebook реализовать единый lifecycle:

```python
experiment = Experiment.create(...)

experiment.print_configuration()
experiment.print_physical_scales()

experiment.initialize()

experiment.visualize_initial_state()

experiment.run(num_steps=...)
```

Методы должны иметь чёткое разделение ответственности.

## Experiment.create

Создаёт:

* конфигурацию;
* grid;
* domain;
* modules;
* particle initializers;
* Poisson solver;
* visualizer;
* diagnostics;
* checkpoint manager.

Но не обязан сразу генерировать частицы.

## Experiment.initialize

Создаёт физическое начальное состояние:

* позиции электронов;
* позиции протонов;
* импульсы;
* alive masks;
* начальную плотность заряда;
* начальный потенциал;
* начальное самосогласованное поле;
* начальные diagnostics.

После выполнения:

```python
state.step == 0
state.time_s == 0.0
```

## Experiment.visualize_initial_state

Логирует статическую и начальную динамическую сцену:

```python
visualizer.log_static_scene(...)
visualizer.log_frame(
    step=0,
    time_s=0.0,
    ...
)
```

Не выполняет particle push.

Не изменяет физическое состояние.

Метод должен быть безопасно вызываемым один раз или несколько раз без дублирования статической геометрии.

## Experiment.run

Продолжает симуляцию с текущего состояния.

Если `initialize()` не был вызван, допустимо либо вызвать его автоматически, либо выдать понятную ошибку. Предпочтительно вызвать автоматически, но явно сообщить об этом.

Если `visualize_initial_state()` не был вызван, `run()` всё равно должен работать.

# Отдельные Rerun sessions

Каждый notebook должен создавать отдельную Rerun recording/session.

Использовать разные application или recording IDs:

```python
application_id = "gyrac_pic"

recording_id = config.name
```

Например:

```text
self_field_only
plasma_with_resonator
full_gyrac
```

При повторном запуске notebook не смешивать данные с предыдущим экспериментом.

Предусмотреть:

```python
experiment.reset_visualization_recording()
```

или корректную повторную инициализацию sink.

# Визуальные различия сценариев

Сцена должна собираться на основе реально подключённых объектов.

Не использовать один renderer, который всегда рисует всё.

Принцип:

```python
scene_renderers = [
    domain.scene_renderer(),
    particle_renderer,
    grid_renderer,
]

for module in modules:
    scene_renderers.extend(
        module.scene_renderers()
    )
```

Поэтому:

## Self-field-only

```text
box domain
grid
electrons
protons
```

## Plasma with resonator

```text
cylindrical domain
grid
electrons
protons
resonator
```

## Full GYRAC

```text
cylindrical domain
grid
electrons
protons
resonator
magnets
magnetic-field indicators
```

Renderer не должен проверять название notebook.

Он должен ориентироваться только на подключённые объекты.

# Конфигурация визуализации

Расширить `VisualizationConfig`:

```python
@dataclass
class VisualizationConfig:
    mode: str

    spawn_viewer: bool = True

    recording_path: Path | None = None

    visualization_stride: int = 10
    diagnostics_stride: int = 1

    max_particles_per_species: int = 50_000

    log_grid: bool = True
    log_domain: bool = True
    log_field_vectors: bool = False
    log_charge_density: bool = False

    energy_color_mode: str = "running_percentile"

    electron_color_min_ev: float = 0.0
    electron_color_max_ev: float = 1.0e6

    proton_color_min_ev: float = 0.0
    proton_color_max_ev: float = 1.0e4
```

Допустимые режимы:

```python
mode = "disabled"
mode = "external"
mode = "file"
mode = "external_and_file"
```

Режим `notebook` можно не поддерживать.

# Критерии готовности notebook-сценариев

Работа считается готовой, если:

1. `01_self_field_only.ipynb` показывает цилиндр плазмы в коробке без резонатора и магнитов.

2. После запуска следующей ячейки частицы начинают двигаться под действием только самосогласованного поля.

3. `02_plasma_with_resonator.ipynb` показывает плазму внутри полупрозрачного цилиндрического резонатора.

4. В notebook 2 магниты отсутствуют.

5. После запуска симуляции в notebook 2 действуют `E_self`, `E_rf` и `B_rf`.

6. `03_full_gyrac_experiment.ipynb` показывает плазму, резонатор и магнитную систему.

7. После запуска notebook 3 действуют самосогласованное, СВЧ и внешнее магнитное поля.

8. В каждом notebook начальное состояние можно осмотреть до запуска simulation loop.

9. Rerun работает в отдельном окне.

10. Разные notebook не смешивают свои recordings.

11. Наличие визуальных объектов определяется подключёнными модулями, а не жёстко заданным сценарием.

12. Все notebook используют общий код из `src/gyrac_pic`.

13. Во всех notebook можно при необходимости включить одновременную запись `.rrd`.

14. Закрытие Rerun Viewer не должно аварийно завершать расчёт. Симуляция должна либо продолжить работу без live viewer, либо корректно обработать потерю соединения.

15. Повторный запуск ячеек не должен создавать бесконечное количество Viewer-процессов. Реализовать понятное управление жизненным циклом внешнего Viewer.
